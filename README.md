🔗 URL Shortener

A simple URL shortener built using Node.js, Express, MongoDB, and EJS.
This project was created while learning core backend development concepts such as routing, middleware, authentication flow, server-side rendering, and database operations.

 Features

Generate short URLs from long links

Redirect to original URLs using short IDs

Server-side rendered UI with EJS

MongoDB for persistent storage

Clean MVC-style project structure

🛠 Tech Stack

Node.js

Express.js

MongoDB

EJS

Mongoose

📂 Project Setup
1️⃣ Clone the repository
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

2️⃣ Install dependencies
npm install

3️⃣ Setup environment variables

Create a .env file in the project root and add:

PORT=8000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key


(Refer to .env.example for required variables)

4️⃣ Run the project
npm start


The app will run on:

http://localhost:8001
